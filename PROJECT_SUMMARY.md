## 🚀 Getting Started (3 Steps)

### Step 1: Setup (2 minutes)
```bash
npm install
cp .env.example .env.local
npm run dev
```
Visit `http://localhost:3000`

### Step 2: Customize (5 minutes)
Edit these files with your information:
- `src/sections/Hero.jsx` - Your name
- `src/sections/Contact.jsx` - Contact info
- `src/data/projects.js` - Your projects
- `src/sections/About.jsx` - Your bio
- `public/resume/` - Your resume PDF

### Step 3: Deploy (3 minutes)
```bash
git push origin main
# Connect GitHub to Vercel and deploy
```

**Total time: 10 minutes to live!** ✅

## 🐛 Troubleshooting

### Common Issues
**Issue**: Dependencies not installing
```bash
rm -rf node_modules package-lock.json
npm install
```

**Issue**: 3D not rendering
- Check WebGL support
- Try Chrome browser
- Clear cache and reload

**Issue**: Build fails
- Check .env variables
- Run `npm run build` locally
- Check console for errors
